# แผนงานการพัฒนา: ระบบสร้างแอคชั่นแบบ Pure JSON Handover (Gamma.app Model)

แผนงานนี้สรุปรายละเอียดเกี่ยวกับการปรับเปลี่ยนระบบสร้างแอคชั่น (Action System) ในโครงการ RAG-LLM จากการเรนเดอร์ภาพนิ่งฝั่งหลังบ้านด้วย Playwright สู่การส่งผ่านโครงสร้างข้อมูล JSON แบบเพียวไปยังฝั่งหน้าบ้าน เพื่อให้หน้าบ้านวาดหน้าสไลด์นำเสนอและอินโฟกราฟิกแบบตอบสนอง (Responsive Web Layouts) และโต้ตอบได้สมบูรณ์แบบ

---

## 1. ประเภทโครงการและบริบท (Project Type & Context)
- **ประเภทโครงการ:** WEB / BACKEND INTEGRATION
- **เทคโนโลยีเป้าหมาย:** FastAPI (Python) + React (TypeScript) + Tailwind CSS v4
- **ขอบเขตการแก้ไข:** ปลดล็อกตัวบล็อก Playwright ใน API Router ฝั่งหลังบ้าน และสลับไปเรนเดอร์คอมโพเนนต์ย่อยฝั่งหน้าบ้านแบบเรียลไทม์

---

## 2. เกณฑ์ความสำเร็จ (Success Criteria)
- **ลดระยะเวลารันเซิร์ฟเวอร์ (API Latency):** ระยะเวลาในการตอบสนองคำขอสร้างแอคชั่นสไลด์ลดลงอย่างน้อย 40% (เนื่องจากไม่มีขั้นตอนการบูตระบบเบราว์เซอร์ของ Playwright บน Backend)
- **ความสมบูรณ์ของโครงสร้างข้อมูล (JSON Validation):** ข้อมูลที่ถูกส่งคืนฝั่งหน้าบ้านอยู่ในรูปแบบออบเจกต์ JSON ที่มีความถูกต้องตามบล็อกโครงสร้างเลย์เอาต์ (Hero, GridCard, Timeline, Stat, SplitMedia) 100%
- **ไม่มีการพึ่งพาภาพสถิต (Zero Static Base64 Image):** การเปิดเล่นสไลด์หน้าบ้านไม่มีการเรียกใช้งานภาพ `data:image/png;base64,...` อีกต่อไป แต่เป็นการโหลดผ่านคอมโพเนนต์ React

---

## 3. ลำดับการไหลของข้อมูลแบบละเอียด (Detailed Data Flow)

### 3.1 ระบบเดิม (Legacy Base64 Screenshot Flow)
1. ผู้ใช้กดสร้างสไลด์ -> ส่งคำขอไปยัง Endpoint `/generate`
2. **Step 1 (หลังบ้าน):** LLM ทำการสกัดเนื้อหาจากเอกสาร
3. **Step 2 (หลังบ้าน):** Coder Model นำเนื้อหามาจัดรูปแบบ JSON รูปแบบหัวข้อและจุดย่อยดั้งเดิม
4. **เรนเดอร์หลังบ้าน:** หลังบ้านเปิดบราวเซอร์ Playwright ล่องหน โหลดหน้า HTML แคปภาพและแปลงเป็น Base64
5. **หน้าบ้าน:** รับ Base64 สตริงขนาดใหญ่มาแสดงในแท็ก `<img>`

### 3.2 ระบบใหม่ (New Pure JSON Handover Flow)
1. ผู้ใช้กดสร้างสไลด์ -> ส่งคำขอไปยัง Endpoint `/generate`
2. **Step 1 (หลังบ้าน):** LLM ทำการสกัดเนื้อหาสำคัญอย่างเป็นระบบ
3. **Step 2 (หลังบ้าน):** Coder Model จัดรูปแบบ JSON เป็นบล็อกตามฟังก์ชันความหมายของข้อความ (เช่น ข้อความขั้นตอนกลายเป็น Timeline, สถิติตัวเลขกลายเป็น Stat)
4. **ส่งผ่านตรง:** Backend บันทึกไฟล์ JSON ต้นฉบับและส่งออบเจกต์ JSON คืนให้หน้าบ้านทันที
5. **หน้าบ้าน:** React พาร์สข้อมูล JSON และส่งให้ `SlideDeck.tsx` รันจัดตำแหน่งกล่องแบบตอบสนองและสับเปลี่ยนสีสันด้วย CSS Variables
