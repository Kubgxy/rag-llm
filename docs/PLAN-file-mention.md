# PLAN: ระบบนำร่องไฮบริดสำหรับการค้นหาแบบระบุไฟล์ (Hybrid File Mention Routing System)

แผนงานนี้จัดทำขึ้นเพื่อแก้ไขปัญหาการแย่งสิทธิ์สืบค้นข้อมูลระหว่างไฟล์กลุ่มข้อความ (Text-based) และไฟล์ตารางข้อมูล (Tabular/CSV) ในแชทเซสชันเดียวกัน โดยพัฒนาให้ระบบรองรับการ Mention ไฟล์และการค้นหานำทางไฟล์อัจฉยิยะ (Auto + Manual Mentions)

---

## 📋 ภาพรวม (Overview)
ปัจจุบันในเซสชัน RAG หากมีการอัปโหลดไฟล์ CSV หรือ Excel ร่วมกับไฟล์ข้อความทั่วไป (เช่น TXT/PDF) โค้ดใน Backend ของ `llm_service.py` จะจับทุกคำถามส่งไปยัง Tabular Agent ทันทีโดยอัตโนมัติ ส่งผลให้ผู้ใช้ไม่สามารถคุยหรือถามข้อมูลไฟล์ TXT/PDF ได้อีก

แผนพัฒนานี้จะแบ่งส่วนการควบคุมออกเป็น:
1. **ฝั่งหน้าบ้าน (Frontend)**: เพิ่มปุ่ม `+` สำหรับเรียกรายการไฟล์ในเซสชัน และสร้าง Autocomplete Popover เมื่อพิมพ์สัญลักษณ์ `/` เพื่อให้ผู้ใช้เลือก Mention ไฟล์ที่ต้องการได้
2. **ฝั่งหลังบ้าน (Backend)**: แกะ Parse คำค้นหาเพื่อหาคำสำคัญของไฟล์ (เช่น `/gemini-code.txt` หรือพิมพ์ `gemini-code` ลอยๆ) และคัดกรองเฉพาะไฟล์ดังกล่าว หากไม่พบการระบุไฟล์ จะใช้กฎดักจับคีย์เวิร์ดคณิตศาสตร์/ตาราง (Rule-based Semantic) เพื่อวิเคราะห์ว่าจะสั่งให้รัน SQL Python หรือจะทำ RAG เวกเตอร์ปกติ

## 🎯 เกณฑ์ความสำเร็จ (Success Criteria)
1. เมื่อพิมพ์ `/` หรือกดปุ่ม `+` ในช่องป้อนข้อความแชท หน้า Frontend จะแสดงแถบเมนูรายการไฟล์ที่มีอยู่ในเซสชันนั้นๆ ให้กดเลือก
2. เมื่อผู้ใช้ป้อนคำถามแบบเจาะจง เช่น `/gemini-code.txt สรุปไฟล์นี้ให้หน่อย` ระบบจะคัดกรอง Vector Search เฉพาะไฟล์ `gemini-code.txt` และตัดผลลัพธ์จากเอกสารอื่นออก
3. เมื่อผู้ใช้ป้อนคำถามแบบกึ่งเจาะจง เช่น `สรุป gemini-code ให้หน่อย` (พิมพ์ชื่อไฟล์ลอยๆ ไม่มี `/`) Backend จะตรวจสอบหาชื่อไฟล์ที่ใกล้เคียงที่สุดในเซสชัน (Auto-linking) และนำทางไปค้นหาเฉพาะไฟล์นั้นโดยอัตโนมัติ
4. หากไม่ได้ระบุไฟล์และเซสชันมีไฟล์ผสม (เช่น TXT และ CSV):
   - คำถามที่มีการคำนวณ/ตาราง เช่น "ยอดขายเฉลี่ยคือเท่าไหร่" จะถูกนำทางไปยัง **Tabular Agent**
   - คำถามทั่วไปหรือการสรุปความเนื้อหา จะถูกนำทางไปยัง **Text-based RAG**
5. ระบบดักจับข้อบกพร่องและ Citation ทำงานได้สมบูรณ์ในทุกกรณี

## 📝 รายละเอียดขั้นตอนการดำเนินงาน (Task Breakdown)

### Phase 1: Backend Parsing & Custom Routing Engine (P0)
พัฒนาตัวคัดแยกและวิเคราะห์เจตนา (Router) ในไฟล์ `llm_service.py`

#### Task 1: เขียนฟังก์ชันวิเคราะห์ Mention และ Auto-Link บน Backend
- **ผู้รับผิดชอบ**: `backend-specialist`
- **ทักษะที่เกี่ยวข้อง**: `python-patterns`
- **ระดับความสำคัญ**: P0
- **การพึ่งพา**: ไม่มี
- **INPUT**: ปรับปรุงเมธอด `query_with_context` ใน `llm_service.py`
- **OUTPUT**:
  - ดึงข้อมูลไฟล์ทั้งหมดใน Session ออกมาตรวจสอบ
  - ค้นหา Pattern การ Mention ด้วย `/ชื่อไฟล์` (เช่น `/gemini-code.txt`)
  - ค้นหาชื่อไฟล์ลอยๆ (Auto-link) โดยแมตช์คำถามกับรายการชื่อไฟล์ในระบบ (ไม่สน Extension และไม่ระบุ Case Sensitive)
  - หากพบการ Mention/Auto-link ให้กำหนดค่า `selected_files` ไปยังไฟล์เหล่านั้นโดยอัตโนมัติ
- **VERIFY**: เขียน Unit test หรือสคริปต์สั้นๆ ในการส่งประโยคเพื่อแยกวิเคราะห์ชื่อไฟล์

#### Task 2: เขียนฟังก์ชัน Rule-based Semantic Classifier (เมื่อไม่มีการ Mention)
- **ผู้รับผิดชอบ**: `backend-specialist`
- **ทักษะที่เกี่ยวข้อง**: `python-patterns`
- **ระดับความสำคัญ**: P0
- **การพึ่งพา**: Task 1
- **INPUT**: ปรับปรุงเมธอด `query_with_context` ใน `llm_service.py`
- **OUTPUT**:
  - เมื่อไม่มีการ Mention ไฟล์เฉพาะเจาะจงในคำถาม
  - วิเคราะห์คำถามด้วย Keyword List (เช่น `เฉลี่ย`, `ผลรวม`, `รวม`, `สถิติ`, `คิวรี`, `ตาราง`, `average`, `sum`, `total`, `count`, `math`, `statistics`, `table`)
  - ถ้าพบว่ามีคำสำคัญเกี่ยวกับตาราง/ตัวเลข และมีไฟล์ประเภทตารางในเซสชัน → นำทางไป **Tabular Agent**
  - ถ้าไม่มีคีย์เวิร์ดตาราง หรือมีเฉพาะไฟล์ข้อความทั่วไป → นำทางไป **Text-based RAG** (Vector search)
- **VERIFY**: ส่งประโยค "สรุปเอกสารนี้ให้หน่อย" และ "ยอดรวมคือเท่าไหร่" ตรวจสอบดูว่าเส้นทางการทำงาน (Routing) ทำงานถูกต้อง

## 🏁 แผนการตรวจสอบความถูกต้อง (Phase X)

### การตรวจสอบผ่านระบบ (Manual Verification)
1. **กรณีมี Mention แฟล็ก `/`**:
   - อัปโหลดไฟล์ `gemini-code.txt` และ `fire_risk_master_FE.csv`
   - ถามว่า `/gemini-code.txt สรุปเนื้อหาตรงนี้ให้หน่อย` -> ระบบต้องใช้ RAG ตอบเฉพาะข้อมูล TXT เท่านั้น
   - ถามว่า `/fire_risk_master_FE.csv ค้นหายอดขายเฉลี่ย` -> ระบบต้องเขียนโค้ดคิวรีเฉพาะจากตาราง CSV เท่านั้น
2. **กรณี Auto-link (พิมพ์ชื่อไฟล์ลอยๆ)**:
   - ถามว่า `สรุปไฟล์ gemini-code ให้หน่อย` -> ระบบต้องเข้าใจและตรวจเจอไฟล์ `gemini-code-xxx.txt` นำมาใช้ตอบ
3. **กรณีไม่มีการระบุไฟล์ (General Fallback)**:
   - ถามว่า `สรุปแชทนี้ให้หน่อย` -> ระบบต้องดึงข้อมูลผ่าน RAG ปกติไม่รันโค้ด Python
   - ถามว่า `ขอค่าเฉลี่ยของ event_id` -> ระบบตรวจพบคีย์เวิร์ดเชิงคณิตศาสตร์ ตาราง และนำทางไปรัน Code-Gen อัตโนมัติ
